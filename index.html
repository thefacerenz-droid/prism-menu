Native answers / v1.8

Prism first reads native question answers where available and remembers correct answers revealed by feedback for repeat questions in the current game. New questions can remain unknown until answered. A set connection is optional. Automatic question and image matching includes the 20-question Goods and Services set by k.a.lee. For other detected sets, Prism automatically tries to read the set page using your existing Blooket session. Browser CORS rules, login requirements, or unavailable answers can block retrieval. If multiplayer does not expose a set ID, paste the host’s question-set link into the menu and choose Use this set. Open connected set is the fallback when automatic retrieval is blocked. Run Prism on that set page once, then return to the game. Private or inaccessible keys remain unavailable. Generic game-mode exploits remain experimental.

Prism reads game data already present in the page. It waits when data is unavailable. The requested “Instant daily 500” control is unavailable; it does not award tokens. Blooket documents earning up to 500 daily tokens through gameplay. Read Blooket’s guide.

Safari and site security settings may block bookmarklets. Mobile compatibility still needs testing on a real iPhone. Game-mode names follow Blooket’s mode overview.
